# 🧩 TP 7 : Classes Abstraites et Modélisation en Java

Ce dépôt contient la résolution des exercices du TP 7 axé sur la conception de classes abstraites, l'héritage avancé et la manipulation de structures arborescentes sans bibliothèques externes.


## Résumé des Exercices
# Exercice 1 : Gestion de la paie des employés

Concepts : Classe abstraite (Employe), méthode abstraite calculerSalaire(), gestion dynamique de la paie.

Implémentation d'une hiérarchie avec EmployeHoraire, EmployeSalarie et Vendeur gérée par la classe Entreprise.

# Exercice 2 : Modélisation d’un système de fichiers

Concepts : Structure arborescente (Composite), parcours récursif, calcul polymorphe des tailles.

Modélisation de fichiers (FileItem) et dossiers (Directory) héritant d'une classe abstraite commune (FsItem).
